# 03 详细软件需求规格（SRS）

> v1.0｜2026-10-25｜本文为拟实现契约，P0/P1 见 [产品范围](01-product-scope.md)。每个需求的验收语句同时是测试设计输入。

## 1. 术语与角色

- **家庭租户**：数据及额度隔离单位；一个家长可加入多个家庭，每次会话只激活一个租户。
- **学生**：家庭下学习档案；儿童会话只能访问绑定学生，不因同家庭就能看兄弟姐妹。
- **原始作业**与**复习作答**分开统计；**待确认**不是做错，也不是做对。
- **自动放行**：满足已验证题型与风险门禁、无需家长确认的机器判定；不代表教师认证。
- **最终业务判定**：当前生效的自动结果或监护人改判，必须标明来源；家长意见不等于评测金标准。
- 家庭所有者：邀请/移除监护人、删除家庭；监护人：管理被授权学生；儿童：自己的学习；平台运营：元数据；平台安全员：审计；运维：运行状态。平台角色默认不看儿童内容。

## 7. 核心业务边界

1. 周报周期为上海时间周一 00:00 至下周一 00:00，月报为当月 1 日至下月 1 日；全部用左闭右开区间，数据库存 UTC。示例：2026-10-19～2026-10-26；月报 2026-10-01～2026-11-01。
2. 原始有效题数只算当前生效版本、可判定且已确认的原始作业题；未作答、待确认、不支持分别列项。另报总受理题数，不能靠剔除难题美化。
3. 原始正确率不被后续订正“刷高”；改判可修正历史，订正成功率和复习正确率独立计算。
4. 周/月复习默认每次最多 20 题或预计 20 分钟，先逾期、再高频、再未掌握；题量可调但不能无限生成。一个 review_task 可关联周/月多个计划，完成只记一次。
5. 孩子只可申请识别修正/重拍；正式改判由授权监护人执行。家长确认会显示“家长确认”，不冒充客观标准答案。
6. 多图部分失败可显示成功部分；整份任务完成不意味着每题已判定。额度按实际处理页结算，供应商失败费用单独记录。
7. 删除、撤回、停用优先于运行中任务：写回前再次检查授权与 deletion_epoch，禁止删除后结果复活。

## 8. 一条完整验收旅程

监护人注册同意 → 建家庭/学生 → 配对儿童设备 → 建课表/关联合法教材章节 → 儿童完成后拍一页数学 → 上传成功得到任务 ID → 进度可恢复 → 一道错题和一道待确认各自显示 → 家长修正 OCR 后生成新结果修订 → 已确认错误入库 → 次日原题复习并记录作答 → 周报可下钻到该题 → 调课更新预习 → 导出数据 → 撤回同意并删除，旧链接和任务写回全部失效。对应任务与测试见 [12](plans/12-backlog-and-traceability.md)。
