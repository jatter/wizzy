# 平台模型目录：正式 API 与 Web

依据：FR-A12、FR-A13/14安全边界、WZ-15；PostgreSQL为正式数据库。

## 实现约定

- 维护供应商、模型标识、固定版本、区域、显示名、用途、合同状态/引用/期限、整数微元成本、目录启停和密钥引用。固定身份不可修改，更换版本需建新条目；密钥引用只写不读，拒绝普通密钥/URL。
- 目录启用不是生产路由准入。没有锁定集与双标证据的条目明确显示未评测、评分为空、不可生产；不使用家长改判或成功页比例伪造评分。真实提供方调用、评测和双人发布继续独立开发。
- 独立平台会话与实时权限；安全管理员可读写，运营仅只读；家庭令牌不可用。每次写入使用操作UUID及CAS，保存不可变修订；业务和最小审计同事务；无删除接口，不销毁历史。
- 正式Vue/Element Plus后台接入列表、筛选、登记、详情/修订、启停；390px可用、错误/空态、键盘标签及会话失效清理；不连接演示数据。
