# 家庭端正式客户端阶段交付

日期：2026-10-26。源码 `frontend/family`；遵循架构要求，使用 uni-app / Vue 3 / TypeScript。此工程连接业务 API，与 `docs/prototype` 演示页面分开。

## 本轮范围与验收

1. 家长注册/登录、家庭创建与切换、学生分页列表/创建/编辑 → 在真实隔离 PostgreSQL 上检查写入及权限。
2. 必需的学生服务授权、独立可选的离线评测授权、五分钟一次性配对及设备撤销 → 验证授权默认关闭、版本冲突、令牌不持久化、撤回后的失效处理。
3. 错题与复习任务的真实读取、家长加入复习、儿童草稿与待核验提交 → 检查真实数据库记录，不展示虚构批改或掌握率。
4. 作业图片选择/拍摄入口、排序/移除、旋转裁剪、逐页上传、提交回执丢失后的幂等重试、任务状态/取消与授权原图读取 → 用真实上传核对页序、裁剪像素、唯一提交及取消后的配额释放。
5. 按北京时间日期、学科和状态筛选作业记录及分页 → 验证筛选失败保留原记录、成功后才标记已应用、日期倒置本地拦截。
6. 周/月报告生成、筛选分页、来源快照下钻、过期提示与显式重建；从报告生成有界复习计划并读取任务实时状态 → 验证无样本不显示正确率、重建保留旧版、响应丢失后相同请求/幂等键不重复创建，以及儿童不能访问报告。
7. 学期创建/分页切换、单双周课程模板、有效周课表、冲突显式确认、单次调课/停课/恢复与历史 → 验证家长可写、孩子只读、版本冲突后重新读取，以及提交回执丢失后先核对实际结果。
8. H5 响应式界面、微信小程序构建 → 分别记录构建、自动化浏览器、真实 API 联调；小程序真机、AppID 和合法域名单独验收。

会话仅驻内存；退出/会话失效/更换家庭或学生清除个人内容；取消旧请求的结果写入。所有数据权限以服务端为准。

## 视觉方案

以作业本的页签与边栏构成学习空间：墨蓝 `#20374b` 为标题、青绿 `#087e80` 为操作、浅蓝纸底 `#f3f7f8`、纯白 `#ffffff` 为内容、橙 `#ad681e` 为待确认提醒、灰蓝 `#647887` 为辅助文字。展示字体采用系统中文黑体，正文系统无衬线，编号与日期等宽。桌面左侧身份与孩子索引、右侧内容；手机改为纵向学生页签与底部导航。用“今日学习页”的竖向刻度作唯一装饰，避免把家庭学习页面做成运营监控大屏。

采用 uni 原生组件和自有轻量设计令牌；不把 Vant Web 或 Element Plus 当作微信小程序组件。依赖以官方 vite-ts 预设的 uni 版本为基线；Vite 5.4.21 覆盖预设 5.2.8 的插件 peer 固定值，兼容性通过两种目标构建核验，审计问题如实记录。
