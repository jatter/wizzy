# 模型评测闭环实施计划

依据：FR-A13/FR-A14、[评测规范](../04-ai-grading-and-evaluation.md)第6–8节。

## 目标与边界

完整目标是可追溯的双人独立标注、分歧裁决、锁定测试集、绑定固定模型修订的评测运行、正式平台报告及发布门禁；不是给目录条目填入一个人工分数。

1. 先实现可验证的服务端统计内核，作为后续运行报告的唯一计算路径。
2. PostgreSQL 私有数据集、样本、盲态双标、第三人裁决和不可逆锁定；合规授权、学生/来源/近重复分组防泄漏。
3. 固定目录修订及 Prompt/schema/rule/image 版本的运行、完整预测集校验、幂等、权限和同事务审计。
4. 正式平台数据集/标注/评测页面与真实 API 联调。
5. 独立实现合同/预算/安全回归/影子试点/灰度/双人审批与回滚，不用数值报告替代发布审批。

## 本切片统计约定

- 五种判定全部保留在受理题分母；自动放行必须单独声明，pending_review/unsupported 不得声明自动放行。正确/错误/未作答也可因待人工确认而不放行。
- 选择性准确率按自动放行结果与金标准判定是否一致计算；误判正确率的分母为全部金标准错误题，而非模型选择作答的错误题。
- 精确率/召回率以“错误题”为正类；非自动放行不算自动检出。缺失分母报告 null，不填0或100%。
- 精确二项区间采用单侧95% Clopper–Pearson；另按学生、页面整簇有放回抽样，使用更保守端点。簇不足或重采样中分母为零不能静默丢弃。
- 报告总体、年级、题型、难度和年级×题型；评测计划必须显式列出关键年级×题型，缺失分层不可因总体均值好看而忽略。所有输入仍保留在总体分母。
- 未作答判正确、不可判输入自动放行、标注为必须拒评却自动放行，均单列安全违规；不能先过滤这些坏结果再计算准确率。
- 数值检查与样本采集目标分别报告；无论结果如何，统计内核始终不授予生产准入。不接受客户端提交的准确率。

## 0020授权前置切片（2026-10-26）

实现 `GET /api/v1/evaluation-policy` 与逐学生 `GET/POST /api/v1/students/{id}/evaluation-consent`。只授权平台内部脱敏离线评测，训练、公开分享和提供方传输均不在本政策内。服务同意和评测同意独立；拒绝/撤回评测不影响服务。撤回服务、源代次变化或监护人权限失效会使旧证明无效；重新同意不能复活旧授权。退出登录不自动撤回持久同意。

专项覆盖60项：HTTP/SQL双层严格校验、真实会话与伪造身份上下文、儿童/跨家庭/失去逐学生权限、版本竞争与同请求并发、审计失败原子回滚、受限角色权限、不可变历史、空库升级/降级及失败迁移回滚。验证使用隔离 PostgreSQL 数据库；共享开发库未在本切片中执行迁移。

后续数据集写入与评测运行须绑定具体授权记录，在使用事务中重新校验并协调撤回。0020交付时尚无样本导入、脱敏处理器、撤回清理、双人标注或真实模型评测。0029已补齐下述人工脱敏采集、实时撤回隔离及独立双标流程；自动脱敏、物理删除和真实模型评测仍未实现。


## 0029数据集、盲标、裁决与锁定（2026-10-26）

- 五张私有表保存数据集、样本、两人标注、第三人裁决和幂等快照；全部 FORCE RLS，运行角色无直接 CRUD，通过固定 search_path 的受限能力函数访问。标注、裁决及锁定后数据不可修改、删除或清表；空库支持降级，存在评测历史时拒绝丢弃。
- 接口根 `/api/v1/admin/evaluation-datasets`，支持列表/详情/样本、创建/采集/标注/裁决/锁定；列表与详情默认50条、最多100条，分页步长按50。写入使用 UUID operation_id 与 expected_revision，幂等回执、CAS及审计在同一事务。
- 采集绑定题目具体修订、来源摘要、学生年级和具体授权记录。按学生、页面、近重复组与归一题干防止 train/validation/test 跨组泄漏；train 标签不授予训练用途。授权、服务同意、来源或逐学生权限失效后，正文、本人标注、金标准及分歧投影隐藏，重新授权不复活旧样本。
- 两位标注员盲标；不同结果由第三人附理由裁决。锁定要求全部样本授权仍有效、完成双标/必要裁决和人工脱敏安全确认，保存不可逆 SHA-256 摘要。没有自动 PII 识别器；人工确认不是自动脱敏证据。
- 正式平台提供数据集列表/详情、两层分页、采集表单、盲标/裁决、锁定确认、摘要、授权失效和权限空态。网络或5xx不确定回执冻结原表单，复用原UUID/请求体重试；409要求关闭核对，401/403和离开页面清理正文，迟到响应不能恢复数据。不将敏感内容写入浏览器持久存储。
- 本次验证：客户端契约 **84 passed**；全平台 Chrome 模拟浏览器 **125 passed（59.0s）**，其中评测专项11项；正式生产构建与全后端Ruff通过；真实页面/API/隔离PostgreSQL **1 passed（47.00s）**，数据库核对草稿、版本、空样本和唯一创建审计。审计联调已改为通过真实分页查找登录事件，新增业务操作不会使测试依赖首屏事件数量。日志 `/tmp/wizzy-evaluation-{client,browser,platform-full,build,real-api,ruff}.log`。
- 前序后端全量证据：**1326 passed、1 warning（358.53s）**，日志 `/tmp/wizzy-backend-evaluation-full.log`；这是数据集后端实现时的历史回归，本次前端/真实联调增量没有重跑整个后端。迁移head为0029；共享开发库未升级或重置。
- 双标一致率仅衡量标注一致性，所有数据集 `production_eligible=false`。0029交付时固定模型修订运行、完整预测导入及统计报告 API/UI尚待实现，已由下述0030补齐离线导入路径；发布治理、真实授权金标准及真实模型质量验收仍待完成，FR-A13/FR-A14与完整项目尚未整体验收。


## 0030固定版本运行、完整离线预测与统计报告（2026-10-26）

- 三张私有表 `evaluation_runs`、`evaluation_run_predictions`、`evaluation_run_operations`，全部 FORCE RLS；应用/worker/dispatcher无直接CRUD或TRUNCATE，只通过固定search_path的受限能力函数。完成后历史不可覆盖；有历史时拒绝降级。
- 创建绑定已锁定且当前可用的validation/test数据集具体修订/摘要、目录模型历史修订及provider/version/region、prompt SHA-256、schema/rule/image版本和必要年级×题型分层，保存不可变manifest摘要。目录启用不构成模型质量或生产准入证明。
- 导入必须携带manifest_digest、expected_revision、UUID operation_id及完整预测数组，精确覆盖所有sample UUID；重复、缺失、额外题或旧版本409。最多50000题，pending_review/unsupported禁止自动放行；HTTP及SQL均严格校验，不接受客户端准确率。运行只从awaiting_predictions/revision1一次转为completed/revision2。
- `source_reference`仅为操作人声明的离线来源，未核验真实提供方执行。没有提供方调用、自动排队或训练；内部评测授权不包含向提供方传输。读写及幂等回执均实时复核具体授权，撤回立即使旧样本不可用，重新授权不复活旧数据；统计期间持有授权协调锁。
- 五个API见[数据模型/API](../architecture/06-data-model-and-api.md#当前固定版本离线评测运行0030)。读权限platform.evaluation.read，写权限platform.evaluation.run，仅security_admin具有写权限；actor+operation UUID同体幂等、CAS、持久写入与最小审计同事务。
