# 家庭入口统一实现记录

日期：2026-11-14。状态：本地实现及验证完成，尚未发布到线上。

## 用户流程

- 家庭端仅保留一个登录页，使用邮箱和密码登录；提供创建账号及“连接孩子的学习设备”次级入口。
- 登录后进入学习空间，通过右上角“家长中心”进入家庭管理。单个家庭自动进入，多个家庭保留选择；支持选择孩子。
- 孩子独立设备输入配对码即可连接，设备名称自动提供；旧 `?end=child` 链接仍可进入设备连接。
- 共用设备点击“开始学习”，服务端签发孩子会话并撤销当前家长会话。孩子会话不能调用家长管理接口。
- 孩子进入“家长中心”时须重新输入家长邮箱和密码；密码错误可继续学习。
- H5 刷新会恢复有效会话，恢复后重新校验身份和权限。会话默认有效期为 24 小时，沿用服务端配置。

## 会话处理

H5 使用同源 API 和 HttpOnly、SameSite=strict Cookie；HTTPS 环境额外启用 Secure。浏览器响应不再向 JavaScript 返回访问令牌，浏览器请求携带专用标记并校验 Origin。原有 Bearer 接口和微信小程序调用方式保持兼容。

退出接口失败时，浏览器仅保存值为 `1` 的待退出标记，下次加载优先重试退出，不恢复此前登录。此标记不包含账号、密码或令牌。新登录成功或退出完成后清除标记。

新增 `POST /api/v1/auth/start-learning`；使用已有会话表，无需数据库迁移。独立设备和共用设备的孩子会话均可由家长撤销。

| 地址 | 页面 |

| `/` | 家庭端统一入口 |
| `/admin/` | 平台管理端 |
| `/admin` | 重定向到 `/admin/` |
| `/family`、`/family/` | 重定向到 `/`，保留查询参数 |

`build-deploy.sh` 已调整家庭端和平台端的构建基础路径以及 nginx 配置。首次发布需要配套更新后端、两个前端和 nginx 配置，避免入口与静态资源路径不一致。本文记录不表示已经执行线上部署。
