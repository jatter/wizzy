# WZ-13 家长周期报告实施与验证

## 范围与约定

依据 03 §7 / FR-P04、06 数据模型与 API、12 WZ-13。正式数据库继续使用 PostgreSQL；只迁移测试隔离库，不修改共享开发库。

- 周一／月初上海时间左闭右开周期；数据库存 UTC。原题按提交时间入期，订正与复习按尝试时间入期。
- 原始有效题数仅当前已确认 correct/incorrect 原题。待确认、未作答、不支持单列；订正不影响原始正确率。
- 不可变报告与逐项来源快照；读时比较当前来源版本显示 stale，显式重建保留旧版，相同来源复用版本。
- 家长判定明确显示 guardian，不作为模型金标准。当前复习尚无独立评估，因此提交只能算待核对，不伪造完成、正确率、掌握或薄弱知识点。
- 仅有权监护人访问；家庭／学生／同意／删除代次在 SQL 能力层检查并加锁；API 审计与写入同事务。
- 报告与来源均有上限分页。周月计划共享 review_task、默认最多20题的功能另作完整验收，不以报告统计切片代替整票完成。
