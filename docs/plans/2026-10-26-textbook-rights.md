# 教材版本与权利审核实施计划（0025）

日期：2026-10-26。对应 FR-A02、FR-A11 / WZ-11 的权利登记和独立审核前置流程；不是整票验收。

## 范围与假设

- 延续正式平台 Vue 3 / Element Plus 和本地 PostgreSQL；共享开发数据库不迁移，使用临时隔离测试库。
- 教材代码唯一，标题可重名；学段、年级、科目、出版社、版本、学年、册次作为教材版本元数据。
- 草稿可缺授权；提交前必须具备权利来源、权利人、凭据引用、授权用途、地区、起止日期。凭据为受控业务引用，本轮不接收正文或权利凭据文件。
- 状态为 draft → pending_review → approved / draft（驳回），pending_review / approved 可撤回；修订限草稿/撤回态，修订后回草稿。已批准内容修改必须重新审核。
- 审核人不可是创建者、当前正文元数据编辑者或本次提交人；审批权限独立于写权限。现有角色安全管理员获三类权限，运营只读；后续独立教材岗位分配不在本轮。
- 到期/未来授权依据上海日期实时计算。approved 仅表示权利审核通过；PDF 校验、解析、抽检、正文发布与检索尚未实现，content_available 固定 false，不能把授权批准当成正文发布。
- 使用 actor + UUID 幂等、CAS、事务内审计、不可变修订、FORCE RLS 与窄 SECURITY DEFINER 能力；不新增运行时表直读权限。
- RTK 在当前环境不可用，使用原生命令，不输出连接串或凭据。

## 实施与验证

1. 数据库迁移与 API：版本、权利登记、提交/独立批准/驳回/撤回、搜索分页、历史。
   验证：真实 PostgreSQL 状态流、权限、过期、幂等/CAS、并发、事务回滚、直接 SQL 与迁移保护。
2. 正式平台页面：目录、分组表单、详情与权利卡片、审核操作、历史和明确的未处理正文提示。
   验证：API 契约单元测试、类型检查/构建、浏览器表单和权限场景、真实 API 联调。
3. 更新功能列表、架构/API、开发状态和本地说明。
   验证：相关回归及全后端测试，记录通过证据和未交付范围。
