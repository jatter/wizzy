# 平台跨账号会话撤销（0031）

对应 FR-A10 平台账号治理。本次补齐独立撤销入口；在线开户、改密、MFA 生命周期和组织数据范围另行实现。

## 行为与验收

1. 安全管理员在账号详情填写撤销原因，撤销目标账号全部已有会话；保持角色、启停和治理版本。本人使用已有“退出全部会话”，跨账号接口拒绝操作本人。
2. 同事务落库不可变回执与审计，回执包含目标、操作者、操作编号、原因、实际撤销的有效会话数和时间。没有有效会话也保存零条回执。
3. 按操作者和 UUID 幂等；相同请求返回原回执，编号复用到其他账号/原因返回409。重试不能撤销首次操作之后新登录的会话。提交与登录共用账号行锁确定生效边界。
4. 每次调用重验会话和权限；仅安全管理员具有专用撤销权限，账号读取权限可以分页查看回执。私有回执表 FORCE RLS，运行角色无直接 CRUD/TRUNCATE；固定 search_path 能力函数执行写入。
5. 页面支持原因校验、明确的操作影响提示、回执与分页、网络/5xx结果不确定时冻结原请求重试、401/403失效清理以及迟到响应隔离。390px宽度可操作。

接口：GET `/api/v1/admin/accounts/{id}/session-revocations`，POST 同路径。POST 接受 `operation_id` 与 `reason`（去除首尾空白后1～500字，不含控制字符）。不接收 token、会话枚举或密码。撤销数量只统计操作边界前未过期且凭据版本匹配的有效会话；其余未撤销历史会话一并标记撤销。

1. 0031迁移与API → 隔离PostgreSQL验证授权、原子性、重放、新登录边界、并发、私有表保护和降级保护。
2. 正式管理页面与API客户端 → 类型检查/生产构建，浏览器覆盖成功、零会话、失败重试、权限变更、移动端。
3. 真实API浏览器联调与相关回归 → 核对数据库回执和审计；更新架构、功能清单和开发台账，明确代码迁移与共享库部署的区别。

本次不升级或重置共享开发数据库，不停止8080原型服务。测试使用随机隔离PostgreSQL。
