# 09 模型选型、准确率门禁与成本预算

> 核验日期：2026-10-25；公开价格不是合同报价。来源及抓取限制见 [来源清单](research/sources.md)。本章没有真实作业准确率或实际 API 账单；所有 Token 用量、复核率和基础设施预算都是规划假设。

## 1. 推荐结论：先验证，不凭榜单采购

**首选验证方案：百炼 OCR + Qwen VL 主判 + 确定性规则 + 少量 Max 复核；DeepSeek Flash 做独立供应商对照。**&#x4E0D;是把最贵模型用于每一道题，也不是让便宜文本模型猜看不清的手写答案。

| 角色      | 首轮候选                                     | 使用边界                                     |
| ------- | ---------------------------------------- | ---------------------------------------- |
| OCR/布局  | `qwen-vl-ocr-2025-11-20`；PaddleOCR 作探索对照 | 保存位置与原文；先测试手写数字、分数、竖式，OCR 成功不等于判题正确      |
| 图文判题    | `qwen3-vl-plus`                          | 对白名单题独立看原图、区分题干/学生答案，输出结构化结果；与规则冲突转待确认   |
| 解释/周报文案 | `qwen3.7-flash-2026-07-15`               | 仅据已确认结构化结果改写；统计由 SQL 计算，不让模型编造数据         |
| 高风险复核   | `qwen3.8-max-0902`                       | 仅在图像本身足够清晰时复核；最多一次，仍矛盾即待确认               |
| 供应商对照   | `deepseek-flash`                         | 当前官方文档支持图像；按实际模型版本、相同题集与可比预算比测，不根据品牌假定质量 |
| 新版本挑战者  | `qwen3.8-flash`、豆包、专项教育批改 API            | 较新不自动替代稳定候选；专项服务能力/价格/转售和儿童数据条款需采购确认     |

Qwen 视觉及 DeepSeek 图像能力来自 S10/S12/S13；技术适配与最终准确性是本项目需证明的事情。`deepseek-v4-pro` 当前不支持视觉，不能直接承担看图主判。模型别名、地区、输入上限、弃用日期均由配置登记；供应商变更需重新回归。[S10–S13]

**同供应商复核不是真正独立证据。**&#x4E24;个模型可能犯同样的错；跨供应商也可能相关。准确率只以独立人工金标准衡量，按 [04](04-ai-grading-and-evaluation.md) 的选择性准确率、覆盖率、误判正确率及置信区间门禁放行。

## 3. 一页作业的透明测算

“标准页”在试点前暂定：一张清晰 A4 作业图、不超过 20 道白名单题、6000 级主判输入 Token；这只是预算工作负载，不是模型分词实测。多页提交逐页计；跨页题不得为了省钱重复丢失上下文。以下调用是**一页批量结构化判题**，不是每题都调用同样一次模型。

通用公式：

```text
调用费用 = (计费输入Token × 输入单价 + 计费输出Token × 输出单价) / 1,000,000
每页期望费用 = (OCR + 主判 + 解释 + 复核率 × 复核单次费用) × (1 + 额外已计费重试比例)
月AI费用 = 页数 × 每页期望费用 + 额外辅导/预习/报告调用费用
```

| 阶段          |         假设输入/输出 Token | 计算                          |         每页人民币 |
| ----------- | --------------------: | --------------------------- | ------------: |
| OCR         |         4,000 / 1,500 | `(4000×0.3+1500×0.5)/1e6`   |      0.001950 |
| VL 主判       |         6,000 / 2,000 | `(6000×1+2000×10)/1e6`      |      0.026000 |
| 简短解释        |           4,000 / 800 | `(4000×0.2+800×0.8)/1e6`    |      0.001440 |
| 基础合计        |                     — | 三项相加                        |  **0.029390** |
| Max 复核      | 6,000 / 2,000，10% 页触发 | `0.1×(6000×12+2000×36)/1e6` |      0.014400 |
| 加 5% 额外计费重试 |                     — | `(0.02939+0.0144)×1.05`     | **0.0459795** |

只有图像清晰且问题属于支持范围才考虑复核；其余直接请求补拍或待确认。这里 5% 是额外消费金额近似值，不是假设所有失败必计费；超时未知消费保留 `billing_unknown`，不能立即按未扣费处理。

若每页都升级 Max，按相同三阶段中以 Max **替换** VL 主判估算：`(0.00195+0.144+0.00144)×1.05=¥0.1547595/页`；若同时保留 VL 再加 Max 则更贵。因此不能靠“全量最高档”同时保证每页≤¥0.10。真实分词/思考 Token 和召回质量可能使本模型失效，必须看试点账单。

## 4. 真实费用账本与产品额度分离

- 每次调用记：租户/学生/页/业务操作、provider、模型实际版本、region、价格版本、各类 Token、预占、实耗、未知结算状态、币种；存整数微元或原币最小计账精度，禁止浮点累计。
- 产品页数额度和供应商收费不是同一账本。相同幂等操作不重复扣家庭额度，但已发生的供应商重复消费仍须真实记账并由平台承担或按明示规则处理。
- 预占按该路由最大允许调用和输出限额计算；并发必须原子扣减可用预算。完成按实际结算释放差额；超时保留未知费用直到对账或采购约定结案。
- 设家庭日/月页数、单页费用硬上限、供应商日预算、全局日/月预算；平台币种各自限额。80% 告警、100% 禁止启动新付费步骤是首版配置建议，实际阈值由负责人审批。
- 必要质量复核预算不足：结果变待确认，不为了省钱降低放行标准。不能为了防超支删除已经可见的历史记录。
- 内容缓存仅在授权范围内使用，跨家庭仅能共享明确授权的公共教材/规则，不共享学生图像/答案。价格表可按月或供应商变更更新，变更后保留历史价格版本。

## 5. 非模型成本与团队投入

| 项目                     |        试点月预算假设 | 说明                                 |
| ---------------------- | -------------: | ---------------------------------- |
| API/Worker、托管数据库、Redis |   ¥1,000～2,600 | 规划占位，不是云厂商报价；可用性和备份要求会抬高成本         |
| 私有对象存储、流量、备份、监控        |     ¥500～1,400 | 依赖原图平均大小、180 天保留与下载频次，需区域询价        |
| 基准 AI：44,000 页         |       约 ¥2,023 | 仅上节作业流水线，不含额外功能                    |
| 上述小计                   | 约 ¥3,523～6,023 | **不含人工、短信、资质、教材、专用 API、税费和应用渠道费用** |

建议 50～100 家庭试点先限制总页数，低负载时减少 Worker，而非按 1,000 学生假设提前购买满配置。图片容量公式：`月页数 × 平均原图MiB × 保留月数 + 派生图/备份`；例如 44,000×2MiB×6≈516GiB 原图，不能只预算当月存储。

团队按 [10](plans/10-implementation-plan.md) 人日估算，不虚构薪酬。标注/复核能力单独预算：`有效题数 × 单题平均标注分钟 × 标注人数 / 60`，还需裁决、招募和授权管理。不要把真实人工成本藏进 Token 价格。

## 6. 采购比测与决策表

硬门禁先行：儿童数据合同/地域/不训练选项、合规用途、质量门槛、超时降级、财务上限均须通过；不通过不能靠加权总分抵消。过门禁后按质量40%、总成本25%、延迟15%、稳定性10%、接口与运维10%比较。这些权重是项目建议，不是供应商评级。

1. 冻结同一授权数据集、图像版本、题型和评分脚本，各候选分别调参后进入锁定集；记录默认/思考模式、输出限制和实际版本。
2. 比较页均/题均消费、P50/P95、待确认比例、改判率；必须同时展示放行准确率和全量覆盖率。
3. 优先在同质量门槛下省钱；如果主模型无法达标，缩小题型/年级白名单，不靠成本理由强行上线。
4. 对通过的候选试点影子跑，核对真实账单；只有已独立过门禁的备选才能自动切换。否则降为“OCR + 家长确认”。
5. 决策记录必须填：样本版本、结果区间、平均费用、失败费用、签字人、回退路由和复核日期。当前这些字段均为**待执行**。
