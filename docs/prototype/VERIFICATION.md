# 三端原型验证记录

> 最近复验：2026-10-26（Asia/Shanghai）。验证对象：`docs/prototype` 内构建后的静态入口，非生产系统。

## 环境与命令

macOS、本机 Google Chrome（Playwright channel `chrome`）、Node.js v26.3.0、Python 3.9.6；依赖固定在 [package.json](ui/package.json) 与锁文件。本轮不将验证机 Node 版本作为生产运行时推荐。

项目根目录执行：

```bash
npm run build --prefix docs/prototype/ui
PLAYWRIGHT_CHANNEL=chrome PROTOTYPE_BUILT=1 npm test --prefix docs/prototype/ui -- --workers=3 --timeout=15000 --reporter=line
```

`PROTOTYPE_BUILT=1` 使用 Python 在 4174 端口提供 `docs/prototype`，因此验证的是交付构建产物。测试不复用已有服务器；运行前保持端口空闲。
