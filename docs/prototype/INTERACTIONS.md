# 小知三端逐页交互与开发交接

> 版本：1.0；日期：2026-10-26。交付对象为 `docs/prototype` 的24个可交互业务页面（孩子7、家长8、平台9）。本文按当前组件行为交接，并列出正式开发要求；“原型可操作”不代表已接真实服务。需求范围以[三端功能列表](../小知功能列表.md)和需求ID为准。

## 1. 使用方法与实现边界

通过 HTTP 打开[总入口](index.html)，分别进入 `child.html#路由`、`parent.html#路由`、`platform.html#路由`。页面布局、控件和状态适合用于评审与开发拆分；字段、接口与数据库约束须同时核对[数据模型与API](../architecture/06-data-model-and-api.md)、[实施台账](../plans/14-development-status.md)、[需求追踪](../plans/12-backlog-and-traceability.md)。接口路径以已有契约及 FastAPI OpenAPI 为准，本文不另造一套接口。

- 原型使用 Vue 3、Element Plus、Vant 和 Lucide。正式平台采用 Vue + TypeScript + Element Plus；正式家庭采用 uni-app。Vant Web 原型不能直接作为微信小程序成品，依据见[UI选型](../research/13-frontend-ui-framework-and-design-system.md)。
- 原型数据保存在浏览器页面会话内；刷新恢复固定数据，三端入口之间不共享真实状态。选择图片、PDF不上传服务器。只有图片裁剪真实改变本地像素；OCR、批改、评分、PDF解析和TXT均为固定演示。
- 孩子默认已配对，以便评审。顶栏端切换只用于浏览原型，不代表切换真实身份或获得权限。默认运营账号只看脱敏元数据；原型中的角色标签不执行服务端RBAC。
- 数据库已定义为 **PostgreSQL，非MySQL**。独立正式工程迁移当前至 `0028_textbook_content`；逻辑模型覆盖范围大于已落地表和接口，逐项状态以实施台账为准。本轮不修改数据库，不把原型状态写入正式库。
- 工整度为P1，学校机构能力为P1待确认；页面存在不改变需求优先级。截图与66项浏览器检查见[验证记录](VERIFICATION.md)。

## 2. 共同交互与正式接入规则

| 项目 | 当前原型行为 | 正式开发验收要求 |
|---|---|---|
| 表单 | 必填、邮箱及业务校验；失败保留输入；保存有反馈 | 服务端再次校验类型、长度、范围与业务唯一性；错误定位字段并保留草稿，不能仅依赖前端 |
| 列表 | 平台公共搜索、状态筛选、分页、详情抽屉；表格可在组件内横滚 | 分页/筛选由接口定义；区分加载、无记录、无匹配、失败、失权，保留重试入口 |
| 状态 | 演示排队、处理中、失败、待确认等结果 | 由服务端状态和修订号驱动；不可用前端“成功”覆盖未知执行结果 |
| 身份与范围 | 家庭切孩子有会话草稿清理；平台展示脱敏标识 | 每条资源校验家庭/学生/组织范围；会话失效清理敏感状态；迟到响应不能恢复上一孩子资料 |
| 并发与重试 | 表单阻止部分重复操作；模拟任务保批次号 | 按接口约定发送UUID幂等键与CAS修订号；响应丢失按原键、原载荷重试；409冲突展示最新状态并要求明确处理，不盲目覆盖 |
| 高风险操作 | 撤销、隐私申请有确认；权限只申请 | 后端验证当前权限、独立审批/二次认证；确认前说明范围与影响，完成后展示状态及回执 |
| 留痕 | 当前会话的行为记录、修订展示或审计行 | 审计记录操作者、时间、对象、理由、前后修订和关联任务；凭据、儿童原图及全文不写普通日志 |
| 移动与键盘 | 390px导航可开关，按钮与标签可访问；1440px桌面布局 | 补真机、屏幕阅读器、焦点回归、键盘及错误播报验收；现有双视口测试不等于全部无障碍验收 |

## 3. 孩子端（7页）

### C-01 今天学什么：`child.html#home`

**需求：FR-C02、FR-C10。** 展示虚构昵称、固定演示日期、今日学习目标、作业入口、到期复习及明日预习入口；点击进入对应流程。概览不能把“待核对”显示为已掌握。

休息提醒默认20分钟，以实际时间差倒计时，可关闭并通过“演示到时提醒”触发；到时确认一次，清理计时器。它是本地提示，不是操作系统推送。正式开发须结合孩子设置、后台/休眠恢复、适龄文案以及真实任务聚合，不能用固定卡片补空数据。

### C-02 设备配对：`child.html#pairing`

**需求：FR-C01。** 展示当前配对状态、6位配对码输入、到期及错误反馈。演示有效码为 `246810`、有效期5分钟；连续错3次锁定；提供已过期、已使用场景用于评审。错误不能放行学习路由。

状态：未绑定 → 校验成功 → 已绑定；失败保留可理解的原因；过期/已用不能再次消费。默认已绑定可撤销，必须二次确认；撤销后清除照片URL、计时器、裁剪、答案、批次、结果、订正和复习草稿，并阻止直接导航进入学习页。正式服务应绑定监护授权、一次性消费、限流和设备会话撤销，禁止把演示码带入生产。

### C-03 拍作业与检查：`child.html#homework`

**需求：FR-C03、FR-C04、FR-C05。** 输入为1–9张JPG/PNG/WebP，每张≤10 MiB，须先勾选已独立尝试完成。类型/超限错误可见，合格图片保留；删除释放本地URL，支持调整顺序、旋转及裁剪。

裁剪弹层按百分比选择区域，校验边界与非零尺寸；确认后使用canvas生成实际PNG并更新尺寸，取消保原图。以旋转后的图像坐标裁剪；异步返回前核对当前图片/会话，避免已移除图片被写回。

状态：选图 → 检查中 → 结果；演示约1.4秒，不实际分析图片。可模拟中断，重试使用同一 `DEMO-xxx` 批次；取消回到选图且保留照片。正式开发应分别处理上传、服务端受理、排队、执行、取消、失败、重试和结果不确定，并对照[家庭客户端计划](../plans/2026-10-26-family-client.md)接入真实上传/任务，避免重复扣额。

结果展示固定题目、题块位置、OCR和状态依据；支持OCR草稿编辑≤500字。待确认题禁用订正、不作为错题，不进入自动判定正确率分母；结果中的五状态语义按需求和数据契约保留，不能压成简单对/错。图片与题块是固定演示对应关系；正式OCR须返回真实页/坐标/修订，原图须有授权短时访问。

### C-04 错题与订正：`child.html#mistakes`

**需求：FR-C05、FR-C06。** 展示固定周长错题，机器原答“13”只读；输入自己的订正，空提交提示；每次提交追加历史，不覆写原答。固定示例只将“26”识别为订正正确，其他作答提供有限提示；这不是通用数学判分器。

原答、机器结论、人工核对、每次订正及后续复习必须分别存储。待确认状态不能自动加入错题；订正成功不能倒改原始正确率或宣称掌握。正式实现见[订正切片](../plans/2026-10-25-correction-attempts.md)，需接入原题证据、逐次核对与修订冲突反馈。

### C-05 到期复习：`child.html#review`

**需求：FR-C07。** 展示D+1固定变式“长6米、宽4米花坛围栏”，来源为演示作业HW-1025第2题；作答≤300字。空提交被拦截；提交后输入禁用并显示“待家长核对”，不自动加掌握率。

支持一条有限提示、跳过、退出保草稿和继续上次复习。跳过/求助保任务，所有行为追加记录；页面会话内切换导航可续做，刷新或撤销配对清空。正式接入见[复习工作台](../plans/2026-10-25-review-workbench.md)与[共享复习计划](../plans/2026-10-26-shared-review-plans.md)：需任务授权、CAS、幂等、持久恢复与人工反馈；D+3/7/14及独立评估不能按此演示记为已完成。

### C-06 明日预习：`child.html#preview`

**需求：FR-C08。** 可用状态展示学科、年级册次、章节、预计时长、目标、关键词、授权来源页和自检问题。发现输入≤300字；空输入提示，记录后展示完成反馈。

可切换缺章节、授权过期场景；切换清空输入及完成状态，缺章/过期不显示伪造页码或来源。恢复演示数据重新开始。正式系统只基于当前有效教材权利及教学进度生成，不以已过期内容继续提供预习；教材无可用正文时展示家长补齐入口。

### C-07 书写观察：`child.html#handwriting`

**需求：FR-C09，P1。** 展示固定排版“明天会更好”、维度82/78/86及练习建议，明确不是用户真实笔迹。切换模糊照片/不支持纸张时拒评，无分数，给出重拍或换纸建议；恢复合格场景显示示例评价。

正式评分应先执行质量门槛，限定纸张、年级及书写任务；低质量不硬打分。该分数与作业批改正确率分开，不用于模型判题准入，需独立校准和可解释证据。

## 4. 家长端（8页）

### P-01 家庭概览：`parent.html#overview`

**需求：FR-P01、FR-P02、FR-P04。** 展示完成计划、有效作答、订正、待核对、趋势与待办，可跳转作业/报告/课表。当前孩子选择器可在林同学与宁同学之间切换；林同学为固定数据，宁同学展示真实空态，不复制另一孩子图表。

切换时清理核对表单、详情抽屉、比较、原因、OCR、判定等状态，并卸载上一孩子内容。正式客户端以孩子ID隔离查询与缓存，拒绝迟到响应，零记录不能生成正确率、薄弱结论或教师意见。

### P-02 作业与核对：`parent.html#submissions`

**需求：FR-P02、FR-P06。** 搜索/状态筛选、打开详情、查看机器原判/原答/依据和修订历史；可修改OCR草稿≤500字，提交改判必须填写依据≤300字。错误保输入；成功展示人工修订，机器记录仍保留。支持模拟失败重试，不实际调用模型。

正式开发对照[核对工作台](../plans/2026-10-25-review-workbench.md)及数据契约：授权原图、不可变OCR修订、逐题核对、冲突提示和派生统计失效更新。家长改判仅成为候选样本；不能未经双标仲裁直接转评测金标准。

### P-03 错题与复习：`parent.html#mistakes`

**需求：FR-P03、FR-P05。** 搜索筛选、选择错题后创建计划；无选择先提示。表单为计划名称、有效日期 `YYYY-MM-DD`、每次时长5/10/15/20分钟；每次最多20题、20分钟。日期必须为真实日历日期，错误保草稿；保存新增会话计划。

正式范围还包括手工收录、错题依据、共享计划逐题任务/改期、题卷和答案分开导出、下载有效期及回填；这些不能按现有选择/计划表单记为完成。核对[共享复习计划](../plans/2026-10-26-shared-review-plans.md)及需求列表，待确认题不自动派生错题。

### P-04 学习报告：`parent.html#reports`

**需求：FR-P04。** 周/月切换、趋势及薄弱点均为固定示例；有效题、待核对与订正分开计数。不能以示例图证明实际学习效果。

正式接入对照[报告计划](../plans/2026-10-25-learning-reports.md)：处理上海时间周期、空周期、过期/重建、证据下钻；导出、自动刷新及薄弱点独立证据按实现台账推进。结果须显示统计窗口、分母与版本；无样本显示“暂无数据”。

### P-05 课表与教材：`parent.html#schedule`

**需求：FR-T01～FR-T04、FR-C08。** 添加/编辑课程字段：星期一至五、开始时间 `HH:mm`、数学/语文/英语、教材章节；必填、时刻格式及相同星期开始时刻重复校验，失败保草稿。支持教材章节进度变更并反馈。

原型只按开始时刻判重复。正式服务须按起止区间及有效课程实例判断冲突，并对照[课表核心](../plans/2026-10-25-timetable-core.md)实现学期、单双周、调停课及历史。课表OCR、提醒与教材/预习联动尚不能从本页验收。

### P-06 家庭与隐私：`parent.html#privacy`

**需求：FR-P01、FR-P09、FR-P10。** 展示家庭所有者、共同监护人与额度。邀请需称呼、有效邮箱；新增“待接受”记录，不发邮件。撤销有确认，家庭所有者不可被移除。

导出/删除申请要求演示验证码 `246810` 及准确输入“确认导出”或“确认删除”；不匹配保输入，成功只新增待处理申请，不导出/删除真实数据。正式实现需监护授权、服务端二次验证、撤权生效、配额结算及任务进度；删除范围包含派生资料与供应商回执，不能以申请成功冒充删除完成。

### P-07 学习讲解：`parent.html#tutoring`

**需求：FR-P07。** 固定题“8×5厘米长方形周长”、原答13、固定错因与讲解稿来源；逐级展开3条提示，达到3条禁用继续按钮。独立点击“查看家长讲解”展开26厘米的完整推导，可收起。完整讲解位于家长区域。

不从固定题推断教师意见，不提供开放聊天。正式模型讲解需授权题目上下文、次数/费用上限与范围控制，必要时拒答；服务端配额不可用前端计数替代，多轮辅导按P1排期。

### P-08 书写观察：`parent.html#handwriting`

**需求：FR-P08，P1。** 与孩子端共享展示及质量拒评逻辑；趋势限定同类示例样本80/84，均值82。标记当前记录无效需填写原因≤300字，空原因被拦截；保留原始分数/原因与无效状态，趋势排除当前记录后剩1个样本、均值80。

正式系统需独立评分修订、样本可比条件、授权和趋势服务；不能跨纸张/任务简单排名，不能删除原评定来制造改善，也不将无效/拒评计为0分。

## 5. 平台端（9页）

### A-01 运行概览：`platform.html#ops`

**需求：FR-A04、FR-A05。** 展示运行指标、任务状态、成本趋势及任务列表跳转，均为演示数。正式页面应显示采集时间、统计窗口、实时异常/延迟、账单对账与预算阈值；监控不可用时显示不可用，不能沿用旧数冒充实时。

### A-02 家庭租户：`platform.html#tenants`

**需求：FR-A01。** 搜索/筛选、分页与抽屉展示脱敏家庭、学生/监护人数、页额度和存储；支持导出当前会话脱敏目录CSV及操作反馈。不得从租户目录隐式进入儿童作业。

正式额度调整、冻结等影响权限/计费的操作须独立鉴权、确认、原因与审计；额度与实际结算以服务端为准，导出范围受权限限制，不能由前端把其他家庭数据拼出。

### A-03 任务队列：`platform.html#jobs`

**需求：FR-A05。** 搜索筛选、任务链路与失败详情；只有失败任务可申请重试，演示状态由失败变排队并记录审计。非失败任务不能被同一操作重新执行。

正式需任务幂等、执行租约、取消、重试次数/退避、死信、费用去重与结果不确定处理；调度动作不等于AI请求已成功。任务详情默认展示技术元数据，访问儿童内容另走有效授权。

### A-04 学生与家长：`platform.html#people`

**需求：FR-A08、FR-A15。** 展示脱敏学生标识、年级、家庭及监护关系；登记必填脱敏标识、家庭租户ID、年级（一至六），新增“等待家庭授权/待确认”。保存不自动绑定，也不开放作业查看。

正式管理区分学生身份、家庭成员、监护关系及学校名册。关系修复、合并、批量导入需逐条授权与错误回执；学校在读关系不等于监护同意，不能用平台管理员身份跳过。

### A-05 学校管理：`platform.html#schools`

**需求：FR-A09、FR-A15，P1。** 新建必填名称、唯一组织编码、地区、学年、授权凭证编号；相同编码拒绝，保留草稿。列表展示组织元数据/待授权范围。名册入口校验所需字段并显示错误，不静默生成授权。

正式学校目录/组织班级/学年在读见[学校目录](../plans/2026-10-26-school-directory.md)、[学校结构](../plans/2026-10-26-school-structure.md)、[学校名册](../plans/2026-10-26-school-roster.md)。正式编码规范、学年范围、组织层级及CAS以API为准，不能用演示校验替代；批量导入回滚、学校管理员组织范围及监护关联另行完成。

### A-06 教材与解析：`platform.html#books`

**需求：FR-A02、FR-A11。** 列表显示教材版本、授权依据、页数、源页映射及状态。上传表单为PDF、教材名称、权利依据；原型按扩展名与大小检查≤30 MiB，名称和依据必填，错误不启动解析。

### A-07 模型与评测：`platform.html#models`

**需求：FR-A03、FR-A12～FR-A14。** 列表、搜索、状态筛选、版本详情与评测报告；模型登记必填名称、供应商、固定版本、用途、处理地域、服务端凭据引用。凭据字段不是API Key，页面不收集真实密钥。新增项为待评测，不进入生产路由。

报告展示模型固定版本、数据集版本、n、批改正确率、覆盖率、误判正确率与单侧95%区间，并说明双人标注/仲裁、审批、灰度预算及回滚。95.2%（476/500）仅固定示例，未达99%门槛；OCR模型不硬填批改正确率。支持评测申请/准入申请反馈，当前抽屉内避免重复提交；不是持久审批或真实发布。

正式评分与准入必须按同一版本的锁定测试集计算：

1. **批改正确率**＝与人工金标准一致的自动判定题数 / 自动判定题数。待确认不当作错，也不能偷偷丢弃；另列**覆盖率**＝自动判定题数 / 纳入评测题数及各题型切片。
2. 准入同时要求批改正确率点估计和**单侧95%下界均≥99%**；不能只凭点估计或模型自报置信度。
3. **误判正确率**＝金标准错误但模型判正确的题数 / 金标准错误题数，**单侧95%上界≤1%**。零分母、区间未计算或样本不足显示不可判定，不宣称达标。
4. 金标准须双人独立标注、分歧仲裁、数据集版本锁定及防泄漏；家长修订只进候选池。展示样本数、选择范围、版本、计算方法与评测证据，不跨题型/地域/版本外推。
5. 正确率之外还需合同/地域/凭据、费用与时延、安全及可用性门禁，独立审批后才可受控灰度；保预算、监控与回滚。目录“启用”不等于判题准入。

正式目录0018与评测授权0020边界见[模型目录](../plans/2026-10-26-model-catalog.md)、[模型评测](../plans/2026-10-26-model-evaluation.md)及数据模型；真实评测运行、区间计算、审批与生产路由仍按实施台账开发。
