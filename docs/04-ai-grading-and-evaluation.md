# 04 AI 作业批改流水线与真实评测

> v1.0｜2026-10-25｜算法和阈值为待验证方案；没有本产品准确率实测。已读取的技术能力来源为 S03/S10～S13；S08 为专项服务采购线索、S14 未读到价格正文，二者不作为已核实能力或价格证据。见 [来源](research/sources.md)。

## 1. 题型支持门禁

| 类型              | MVP 行为  | 自动放行前提                   |
| --------------- | ------- | ------------------------ |
| 整数四则、带括号的封闭算式   | 首批候选    | 题干及答区明确；受限解析器求值；视觉核验 OCR |
| 简单数值填空、大小比较     | 首批候选    | 有唯一可验证答案、无题意歧义           |
| 分数、小数、单位换算、竖式   | 逐项开白名单  | 精确有理数/单位规则、对齐与进位经过专项评测   |
| 图形/钟表/连线/应用题过程  | 待确认或辅助  | 不因最终数值相同就认可全部过程          |
| 语文拼音、字词、英语拼写    | P1 客观子集 | 多解表、教材版本、大小写/标点规则已审核     |
| 阅读、作文、开放表达      | P1 辅助建议 | 显示评价维度与证据，不自动认定唯一标准/学校分数 |
| 涂改不清、缺题干、老师批注覆盖 | 待确认/重拍  | 先修复输入，不用模型猜答案            |

题型与年级分别开关；不能一次数学白名单通过就开放所有数学。确定性计算也依赖 OCR，错误读取“3/8”会造成精确但错误的结论。

## 2. 流水线和输入输出

| 阶段      | 输入 → 输出                   | 核心规则                                           |
| ------- | ------------------------- | ---------------------------------------------- |
| P0 接受   | 作业版本 → 页级 job、预算预占        | 同意、授权、配额；每页 trace_id                           |
| P1 图片净化 | 私有原件 → 旋转/去 EXIF/纠偏图、质量指标 | 不把模糊当字差；保留坐标变换矩阵                               |
| P2 OCR  | 净化图 → 文本块、框、公式、原始返回引用     | 无供应商概率则 confidence=null；文字不能反向覆盖原图             |
| P3 切题   | 页及文本 → question、题干/答区/批注区 | 跨页题可人工关联；错位、缺答区进入待确认                           |
| P4 结构化  | 题块 → 题型、学生答、单位、候选知识点      | 逐字抄录先于求解，禁止“自动纠正”学生错答                          |
| P5 验算   | 审核题型/结构 → 规则结果与独立视觉结果     | 规则使用白名单解析树，绝不 eval/执行 OCR 内容                   |
| P6 风险路由 | 双轨证据 → 放行/二次复核/待确认        | 多解、OCR 冲突、图形、涂改、单位、答案泄露风险                      |
| P7 辅导   | 已确认判定/题干 → 分级提示、错因建议      | 不确定判定不生成肯定语气；不暴露隐藏答案                           |
| P8 写回   | 校验结果 → 修订、错题、事件、账单        | expected_revision/deletion_epoch 校验，事务与 outbox |

OCR 与视觉模型均候选云服务；PaddleOCR 用于对照。首版不为“开源免费”部署 GPU。模型必须看包含学生原答的题块，不能只根据 OCR 给原图正确性背书。[S03/S10/S13]

## 3. 结果结构（接口约束样例）

```json
{
  "schema_version": "1.0",
  "question_id": "q_demo_01",
  "source_revision": 2,
  "question_type": "integer_arithmetic",
  "stem": "12 + 8 = ?",
  "student_answer_raw": "21",
  "student_answer_normalized": "21",
  "reference_answer": "20",
  "bbox": [0.10, 0.20, 0.80, 0.35],
  "ocr_confidence": null,
  "verdict": "incorrect",
  "decision_source": "rule_and_visual_gate",
  "reason_codes": ["ARITHMETIC_MISMATCH"],
  "evidence": [{"kind": "answer_region", "page": 1}],
  "risk_flags": [],
  "knowledge_point_ids": ["math.integer.add"],
  "hint_level_1": "先算个位，再检查进位。",
  "model_run_id": "run_demo_01",
  "needs_guardian_review": false
}
```

所有字段经 Pydantic/JSON Schema 校验；坐标 0～1 且 x1<x2、y1<y2；题号来自任务白名单。非法枚举、缺证据、超长文本、未知知识点不可直接入库。JSON 格式修复最多一次并计费；仍失败转待确认。`reference_answer` 是内部/家长字段，儿童接口按提示层级裁剪，不能只在 UI 隐藏。

## 4. 判定、置信与纠错

- 判定枚举：correct / incorrect / unanswered / pending_review / unsupported。页面 job succeeded 只代表处理完成。
- 风险门禁使用可观察特征和离线校准：图像质量、OCR 与图像差异、题型、规则冲突、答案区域完整性。没有校准前默认更保守。
- 双模型相同结论可能共享偏差；OCR 错误会传染所有下游。独立复核必须重新看原图、独立解题，不把首个参考答案当事实。
- 二次复核可采用另一供应商；不达标时继续 pending_review，不无限重试。首期每题最多一次质量复核。
- 人工更正生成不可变 revision，旧机器结论保留；有效指针更新同时使错题、掌握状态、报告和预习建议失效重算。
- **规划中的 OCR 更正重跑**应创建新 source_revision；对旧版本迟到响应丢弃。人工结果优先级高于旧自动结果，不允许后台重跑悄悄覆盖。当前 0009 仅实现题目级不可变 OCR revision 与监护人 CAS 更正，保留机器原文、原答及历史；不创建新 source_revision、不外呼或自动判对错，更正后保持 pending_review。OCR 文本更正不是答案正确性的金标准，不能据此计算模型正确率或评分；人工判定与重跑仍待后续实现。
- 监护人纠错只能修正本家庭；进入共享题库/评测集需另行脱敏、授权与教研双审。

## 5. 工整度方案（P1，不作为主成绩）

1. 先检查图像清晰、光照、角度；不合格返回 unscorable + 原因。
2. 初始只评价有足够中文手写字的连续作业片段；建议至少 30 个可辨字，此阈值需试点评估。纯算式、印刷内容、英文不沿用中文量表。
3. 四维：字形可辨识、大小一致、字距/行距、布局整洁；每维 1～5 级，有图上证据和一句具体改进建议。样本不足的维度不评分。
4. 满足可比条件才给可选 0～100 辅助综合分：四维均有效，等权转换 `sum(levels)/20*100`；只显示整数，不制造小数精确感。任一维无效仅展示有效维度。
5. 同学生同量表/相似纸张与任务的趋势才比较，量表版本改变分段展示。禁止书法等级、智力/性格判断、学生公开排名。
6. 验收由教研双标得到等级区间；目标加权 Kappa≥0.70 且至少 90% 维度误差≤1级，不达标就只给描述建议。门槛为产品目标，不是已证明指标。

## 6. 基准数据集建立

- 仅在合规授权下收集；授权服务处理不自动包含训练/公开数据集用途。开发前先用合成/成人代写验证管线，不能用它替代真实验收。
- 第 1～2 周至少 200 页/2,000 题探索集，覆盖 1～6 年级典型输入；锁定首批年级/题型后，发布评测集规划至少 1,000 页/10,000 题，≥100 名学生、多个学校/纸张来源。数量是采集任务，不是已存在数据。
- 先按学生和作业来源分组，再划分开发/校准/锁定测试（建议 60/20/20）；相同教材页、近重复扫描、同一模板批量变式防泄漏。固定比例不足各分层样本时扩大集，不挪用锁定测试调 Prompt。
- 分层：年级、题型、正确/错误/未答、多解/单位、工整度、模糊/阴影/倾斜/涂改、老师红笔、跨页。风险层过采样并分别报告，不混成单一好看均值。
- 两名有小学教学经验的标注人独立标注题干/学生答/可判定性/正确答案/判定/坐标，分歧由第三人裁决；记录一致性和判例手册版本。
- 人工判不清即标不可判定，不能用模型答案作为真值。标注队列不默认开放整份儿童个人信息。

## 7. 指标、样本量与发布门禁

定义 `A=自动放行数`、`N=测试集受理题数`、`E=自动放行中与金标准冲突数`。

| 指标       | 定义/目标                                         |
| -------- | --------------------------------------------- |
| 选择性判定准确率 | `(A-E)/A`，目标点估计≥99%，发布还要求单侧95%置信下限≥99%        |
| 自动覆盖率    | `A/N`，首批白名单目标≥60%；同时报告全量真实输入覆盖率，白名单外不得从全量分母隐去 |
| 误判正确率    | 金标准错误却自动判正确数 / 金标准错误总数，目标单侧95%上限≤1%           |
| 误判错误率    | 金标准正确却自动判错误数 / 金标准正确总数，单列上限和人工负担              |
| 其他       | 切题召回/错配、答案字符错误率、pending 比例、人工改判率、P50/P95、每页实耗 |

用单侧 Clopper–Pearson 区间；零错误时 n≥299 才能在独立二项假设下给约99%单侧下限；有错误时需更大样本。题目存在学生/页面相关性，还需学生/页面簇 bootstrap 的保守区间并用更保守结论。不能把 10,000 相关题等同独立样本。

关键题型每层自动放行及金标准错误样本不足时标“证据不足”，保持关闭；不能把所有年级混合过线。困难题安全拒评、红笔答案污染、未作答不可强判为正确，为额外硬门禁。质量优先级高于≥60%覆盖；无法同时达标则缩白名单或人工确认，不降准确门槛。

## 8. 版本与持续监测

每次记录 provider/model_id/供应商实际版本（若可得）/region/prompt_hash/schema_version/rule_version/eval_set_version/图像处理版本。别名漂移不算可复现固定模型；无法固定时每日哨兵集、漂移预警、关闭自动放行。

发布流程：离线锁定集 → 安全回归 → 已授权试点影子模式 → 5%灰度 → 20% → 全量；每阶段至少覆盖晚高峰与足够样本。人工改判率上升、假阳性严重个案、成本/耗时超预算立即冻结对应题型。提供一键切为“识别+待确认”；后备模型也必须独立过门禁，不能以故障为由偷偷用更差模型。

## 9. 当前工程实现边界（2026-10-26）

以上为目标流水线与评测规范，不代表已经接入。当前工程已实现单 structure 阶段受控消费者、`1.0-conservative` 内部结果契约及当前授权下的保守结果只读投影；题目只能 pending_review/unsupported、必须监护人复核，不能输出自动正确/错误或参考答案。第 3 节 `1.0` 示例判定不是当前已实现契约。

- 提供方必须显式注入：prepare 仅本地预检/私有输入读取，无外呼；invoke 仅一次、关闭 SDK 重试并遵守传入的 30 秒超时，具体超时中断须由真实适配器验证。没有默认模型、自动回退、格式修复再调用或完整 OCR/verify/tutor 串联。
- 固定 provider/model/version 只记录身份，不替代授权、隐私及评测发布准入。0029已实现人工脱敏采集、独立双标/裁决及摘要锁定；0030已实现绑定固定数据集/模型修订及prompt/schema/rule/image版本的离线预测运行、完整题集导入与服务器六指标/区间/分层报告。source_reference仅为操作人声明，未调用或核验提供方，production_eligible始终false；真实授权金标准、真实提供方和发布门禁仍未验收。
- 调用围栏前失败可有限恢复；许可可能提交后未知响应/费用进入待对账，不自动再调用。费用未知不当作 0、不结算结果；迟到回执不复活被取消或撤回的业务。已知合成金额不等于真实账单已核验。
- `GET /api/v1/submissions/{submission_id}/result` 仅向当前有权监护人/对应儿童展示待复核题文、原始作答、bbox/置信度和证据；部分/全失败页可见受限错误码，不暴露内部调用与费用。撤回/旧删除代次不可读，读取不触发模型或结算；没有真实评测依据，不能将成功页比例或这些 pending_review 结果当作模型评分。
- 自动化使用测试提供方及真实隔离 PostgreSQL/Redis，证明的是消息/权限/结算边界，不是模型正确率、供应商幂等或商业上线能力。最新证据见 [14](plans/14-development-status.md)。

- 0020新增逐学生独立评测授权：公开政策与监护人读取/授权/撤回 API，政策限定经脱敏和隐私检查后的内部离线评测，明确不含训练、公开分享或提供方传输。服务同意不会自动包含评测；撤回评测不影响原有服务，撤回服务使旧评测授权失效且再次同意不复活旧授权。持久决定不随登录退出而撤销。不可变历史、实时权限、CAS/幂等及审计已实现；0029已补齐具体授权绑定、采集/使用实时复核、失效后隐藏正文/标签及数据集双标/裁决/锁定。自动脱敏、物理删除、真实模型质量验收仍待实现（0030已实现固定版本离线运行、完整预测导入和服务器统计报告），不能据此宣称已有通过验收的真实金标准。接口与物理模型见[数据模型/API](architecture/06-data-model-and-api.md#当前逐学生模型评测授权0020)。
