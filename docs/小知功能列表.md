## 6. 数据库与数据模型决策

**当前方案：PostgreSQL，不是 MySQL。**依据 `architecture/06-data-model-and-api.md`：UUID 主键、UTC `timestamptz`、租户复合外键、JSONB 用于版本化变动证据、行级安全（RLS）辅助隔离。平台管理补充实体建议见该架构文档，包括学校、成员关系、RBAC、模型注册/版本/路由、评测集/金标准/指标、教材资产/解析任务/TXT 章节。

**实现状态：已具备部分物理数据库实现，不是全部逻辑模型已建表。**`backend/migrations` 已有 Alembic 迁移，代码 head 为 `0033_review_plan_history`，数据库连接、RLS/受限角色与 PostgreSQL 隔离集成测试已落地，具体切片见本文开头及 [数据模型/API](architecture/06-data-model-and-api.md)。全量回归结果与各增量验证命令见正式工程台账；测试使用随机隔离库，不代表共享开发库或生产库已经升级。共享开发库仅有此前 0006 的记录，本轮未迁移或重读。模型目录、学校目录/组织/名册、教材版本/权利审核及各自不可变修订物理表/API已实现；教材内嵌文本提取及人工校核/发布、授权单页原PDF预览已补至0028。图片OCR、AI检索、真实模型评测发布及账号邀请/MFA生命周期/学校管理员范围等表/接口仍按实施台账补齐；备份恢复与生产验收也未完成。新增切片仍需冻结字段、索引、约束并补迁移与越权测试。若改 MySQL，应单独评估 RLS 替代策略、JSON/全文索引、隔离与迁移成本后更新 ADR，不可仅替换连接字符串。

## 7. 页面/流程开发验收清单

- **孩子：**配对 → 首页 → 拍摄及多页排序 → 上传/重试 → OCR 定位 → 分题结果 → 订正 → 复习作答 → 预习自检；覆盖断网、模糊图、取消、退出恢复。
- **家长：**同意/家庭和多孩子 → 授权监护人 → 提交列表/详情 → OCR 修正/改判 → 错题入库 → 计划与复习 → 周报下钻 → 课表/教材章节 → 导出/撤回/删除；覆盖学生越权、并发改判、空报告。
- **平台：**租户/任务/成本 → 注册模型 → 绑定锁定评测集 → 评测指标和证据 → 门禁/双人审批/灰度/回滚；学校与学生/监护人关系管理；后台 RBAC/MFA；教材权利登记 → PDF 解析 → TXT 章节映射/抽检 → 发布/撤回；删除和内容访问工单 → 审计。每条需 API、数据库、审计及角色权限验收。
